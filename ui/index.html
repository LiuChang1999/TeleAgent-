01 / READ

先看登录资料

每 3 秒读取本地账号与 Cookie 信息。用户名、手机号来自匹配账号 ID 的缓存；打码号码维持原样。没有缓存时显示“未缓存”。

02 / SWITCH

一键自动切换身份

点击“切换并打开”，程序自动保存当前会话、关闭应用、选择账号并重启，随后核对目标身份。已有登录会话保持在各自目录。正在执行任务时会暂停切换，避免中断工作。

03 / SIGN IN

历史会话可能需要重新登录

凭据缺失、Cookie 到期或身份缓存不一致时，旧会话未必还能使用。“重新登录所选”会备份并清理该账号的登录状态，保留聊天数据库，由你手动完成登录。

04 / RESTORE

本机退出与服务端注销

“本机退出登录”只清理本机登录状态，不注销服务器会话。服务端注销请使用 TeleAgent 自带的退出登录。最近一次操作可以在“会话备份”中恢复；检测到新登录数据时会停止覆盖。

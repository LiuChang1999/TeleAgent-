本次发布包含 v0.5.0 以来的全部更新。

- **账号管理**：搜索、分组、置顶、筛选，以及托盘快速切换。
- **操作记录与备份**：最近 200 条操作历史、空间统计、清理预览、保留份数和当前快照保护。
- **轮询登录**：按筛选范围逐个核对并保存会话，失败记录原因并提示；支持停止，正常结束后尝试回到原账号。
- **设置中心**：系统托盘、关闭和最小化行为、手动启动或自启时收起、当前用户开机自启、系统通知、刷新频率及恢复默认。
- **单文件 EXE**：内嵌微软签名的 WebView2Loader.dll 和许可证，启动时自动核对并释放到当前用户缓存，无需旁置 DLL。

下载 `TeleAgent-Account-Desk-v0.7.0-win64.exe` 可直接运行；ZIP 另含使用说明和许可证。`SHA256SUMS.txt` 提供两个分发文件的校验值。

运行前请先从托盘退出旧工作台。目标电脑需要安装 TeleAgent 和 WebView2 Runtime。开机自启默认关闭，需在设置中心保存启用。失效登录或验证码仍需本人在 TeleAgent 中处理；本地检查不等同于服务端会话验证。

Windows 64 位 Release 构建已通过十组回归与界面测试，并验证 `--autostart` 入口。轮询使用模拟账号验证；启动项写入测试使用隔离注册表项，真实开机启动项未被改变。
